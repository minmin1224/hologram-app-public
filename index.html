🔺 3Dホログラムメーカー

自分の絵や写真を
3Dホログラムで浮かび上がらせる

描いた絵やお気に入りの画像を取り込んで、ピラミッド型リフレクターで宙に浮いているように映し出せるアプリです。向き・大きさ・位置の調整や背景の透明化もブラウザだけで完結します。

アプリを起動する できることを見る

できること

インストール不要、スマホのブラウザだけで動作します

🖼️

好きな画像を取り込む

自分で描いた絵やお気に入りの写真をファイルから選んで取り込めます。QRコードを読み取って画像URLから取り込むこともできます。

🔄

向き・大きさ・位置を調整

スライダーやドラッグ操作で回転・拡大縮小・位置を自由に調整。スマホなら2本指のピンチ・ねじり操作にも対応しています。

✂️

背景を透明化

白い紙に描いた絵や単色背景の写真なら、ワンタップで背景を自動検出して透明化。被写体だけが浮いているように見せられます。

🫧

呼吸アニメーション

ONにすると画像がゆっくり上下に動き、静止画でもより生きているような浮遊感を演出します。

🔺

4面同時プレビュー

調整画面の時点から、ピラミッドの4面すべてに映る見た目をその場で確認できます。

💾

自動で保存

読み込んだ画像や調整内容は端末内に自動保存され、次回開いたときも同じ状態から続けられます。

📱

ホーム画面に追加(PWA)

スマホのホーム画面に追加すれば、アプリのように1タップで起動できます。

追加のやり方を見る →

イメージ

画面の中央にピラミッド型リフレクターを置いて使います

※ ピラミッド型リフレクター(透明なアクリル板やOHPシートなどを四角錐状に組んだもの)は、このアプリとは別にご自身でご用意ください。

使い方

  1. 1画像を選ぶ「画像を選ぶ」またはQRコードの読み取りで、絵や写真を取り込みます
  2. 2調整する回転・拡大縮小・位置を調整し、好みで背景透明化や呼吸アニメーションもONにします
  3. 3ホログラム表示をタップ画面全体に4面分の映像が表示されます
  4. 4リフレクターを置くピラミッド型リフレクターを画面の中央に乗せて、浮かび上がる映像を楽しみます

ホーム画面に追加する

インストールすれば、次回からアプリのように1タップで開けます

Android (Chrome)

  1. スマホのChromeでアプリのURLを開く
  2. 右上の「⋮」メニューを開く
  3. 「アプリをインストール」または「ホーム画面に追加」をタップ
  4. 表示名を確認して「インストール」

iPhone (Safari)

  1. iPhoneのSafari(他のブラウザ不可)でアプリのURLを開く
  2. 共有アイコン(四角に上矢印)をタップ
  3. 「ホーム画面に追加」を選択
  4. 表示名を確認して右上の「追加」

インストールしなくても、ブラウザのままでも全ての機能を使えます。

アプリを起動する
データについて: 取り込んだ画像や調整内容はすべて端末内(ブラウザのストレージ)に保存され、サーバーには送信されません。QRコードから画像URLを取り込む場合のみ、そのURLへの通信が発生します。
